# Sharrowkin · Паутина кода

Карточный рогалик для хакатона «Человек против паука». React + TypeScript + Vite, Zustand, Vitest. Без сервера, аккаунтов и внешних графических ресурсов.

## Запуск на Windows

Нужен Node.js ^20.19.0 или >=22.12.0 и npm.

```text
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite. Проверки: `npm test`. Production: `npm run build`, затем `npm run preview`. Каталог `dist` можно разместить на статическом хостинге.

## Публикация на GitHub Pages

Целевой репозиторий: https://github.com/MatweyNazarenko/SharrowkinJam.
Ожидаемый адрес после успешной публикации: https://matweynazarenko.github.io/SharrowkinJam/.

1. Загрузите исходники, включая `.github/workflows/deploy.yml`, в целевой репозиторий (ветка `main` или `master`). Не загружайте `node_modules`, `dist`, `.env` и служебные папки.
2. В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Во вкладке **Actions** запустите **Deploy game to GitHub Pages → Run workflow**, если публикация не началась автоматически.
4. После успешного задания `deploy` ссылка появится в окружении `github-pages`. Следующие push в `main`/`master` автоматически проверят и опубликуют игру.

Личные токены и дополнительные secrets для workflow не нужны: используется встроенный `GITHUB_TOKEN`. Доступность Pages зависит от видимости репозитория и тарифа GitHub.

`npm run build` создаёт сборку с путями `/SharrowkinJam/`. Для локальной проверки выполните `npm run preview` и откройте `/SharrowkinJam/` на адресе, напечатанном Vite. Разработка через `npm run dev` остаётся в корне `/`.

Сохранения останутся локальными в браузере; прогресс с localhost не переносится на новый домен автоматически.

## Игра

Выберите программистов или пауков. Пройдите 8 узлов, включая 5 боёв и босса. В начале хода — 3 энергии, добор 5 карт. Карта разыгрывается нажатием, цель всегда текущий противник. Противник показывает намерение. Остаток руки сбрасывается при завершении хода.

Особые карты сначала списывают собственное здоровье, игнорируя броню. При 0 HP — поражение до применения эффекта. Здоровье сохраняется между боями. Награда — одна из трёх карт или пропуск. После каждой победы автоматически восстанавливается до 12 HP. Две мастерские дают один выбор: бесплатные +2 урона всем атакующим картам, +2 брони всем защитным картам либо показанная особая карта за 40 фрагментов. Усиления складываются до конца забега; отдыха больше нет. Событие выбирается из четырёх вариантов.

Броня действует до следующего хода владельца; яд/баг срабатывает перед ходом заражённого и уменьшается на 1. Слабость: −25% атаки; уязвимость: +50% входящего атакующего урона. Округление вниз. Яд и цена HP не являются атакующим уроном.

Автосохранение каждого действия, выбранная сторона и рекорд хранятся в localStorage под `sharrowkin-run-v1`. Обновление страницы продолжает игру. Выход через меню удаляет забег, но не рекорд. При отказе хранилища показывается предупреждение.

## Сложность

Перед забегом выберите лёгкий, обычный (по умолчанию) или сложный режим. Лёгкий: здоровье и прямые атаки врагов ×0,8, лечение после победы до 16 HP. Обычный: исходные числа, лечение до 12 HP. Сложный: здоровье и прямые атаки врагов ×1,25, лечение до 8 HP. Числа округляются до ближайшего целого; слабость и уязвимость применяются затем по обычным правилам. Броня и заражение врагов, карты, энергия, награды и события не меняются.

Сложность фиксируется на весь забег, сохраняется при перезагрузке и повторе. Старые сохранения без поля `difficulty` используют обычные правила без пересчёта текущего боя. Обучение остаётся на обычном режиме. Рекорд побед общий для всех сложностей; баланс требует плейтеста с игроками.

## Структура

- `src/data.ts` — 36 карт (по 6 особых на сторону), 4 обычных/элитных врага и босс на каждую сторону, 4 события.
- `src/engine.ts` — чистые переходы состояний, seeded RNG, бой и маршрут.
- `src/store.ts` — Zustand, проверка и сохранение состояния.
- `src/ui/` — React-интерфейс, собственные SVG-портреты и процедурные 3D-модели Three.js.
- `src/ui/humanModel.ts`, `spiderModel.ts`, `modelParts.ts` — шесть вариантов персонажей с иерархией суставов, общей геометрией и материалами.
- `src/ui/battleCues.ts`, `fighterAnimation.ts`, `battleEffects.ts` — визуальные события карт и хода врага, позы и эффекты; не меняют движок и сохранения.
- `src/ui/BattleScene.tsx` — арена, камера, освещение, WebGL и резервные 2D-портреты. В ожидании — до 30 кадров/с; в боевом действии — частота экрана. Анимации учитывают системное уменьшение движения и переключатель паузы. В паузе сцена перерисовывается только при изменениях.
- `src/ui/useBattlePresentation.ts` — короткое завершение последнего удара, пока награда уже доступна. Учебный и обычный бой используют одну сцену.
- `src/ui/*.test.ts` — проверки моделей, суставов, визуальных событий, границ сложности геометрии и очистки GPU-ресурсов.
- `src/engine.test.ts` — регрессии и 2000 симуляций настоящего движка.

Программисты наносят атакующими картами +3 урона, пока у них есть броня. Пауки получают тот же бонус, пока противник заражён. Порядок карт важен: сначала защита или яд, затем атака. Карты в руке показывают урон с учётом бонусов и статусов (до поглощения бронёй врага). Старые сохранения поддерживаются: фаза `rest` теперь открывает мастерскую; отсутствующие усиления считаются нулевыми. Отдельные ресурсы технического долга и паутины не введены: используем согласованный ограниченный набор статусов. Маршрут линейный, случайны раздачи, награды и события. Звука, реликвий и метапрогрессии нет. Целевые 10–15 минут требуют проверки с живыми игроками; бот не измеряет человеческую сложность.

## Демонстрация за 60–90 секунд

Выбор стороны → карта маршрута → первый бой → намерение врага → карта защиты → особая карта с потерей HP → завершение хода → награда. Покажите правила и обновление страницы с сохранённым боем.
